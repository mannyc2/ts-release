## Count definitions and honest comparisons

The immutable original denominator is **22,916 product/Action source + 55
Action-YAML product input = 22,971**. The 55 lines were recovered from
`apps/ts-release-action/action.yml`; they were not an invented capability policy.
Root package JSON and build tsconfigs were absent from that original numerator.
The new exact public/private manifests and tsconfig templates are reported
separately for every layout and added in a conservative combined view in JSON.
Package boundaries, exports and release coordination are not free because a
historical line-count classifier excluded their metadata.

The new Action manifest has 22 lines. There is no runtime-generated provider
allowlist, central release-config schema or parallel capability registry. Build,
check and delivery script paths/contracts are specified in `layout.json`; their
unimplemented bodies have no fabricated measured line count. They are tooling
cost, and the final maintenance ledger must include their actual source.

Formatting is another material limit. The selected machine is 1,024 physical
versus 1,145 TypeScript-printer lines; current adoption/Apple is 545 versus 648;
native Git construction is 122 versus 157; checksums are 68 versus 77. Conversely,
the preserved overlay has 22,916 physical versus 18,432 printer lines. These
diagnostics expose style differences; they do not implement the original
`semantic-source/v3` contract or prove a 50% normalized reduction. Dense source,
generated output, moved code or declarations cannot manufacture a pass.

## Exclusions with explicit cost

Existing upstream effect-build libraries supply the selected producer operations.
The actual published consumer and owned-adoption experiments require **zero new
upstream implementation lines** for streaming files and bounded trees. Existing
dependency code is not claimed as deleted project code. Any newly maintained
upstream implementation must be charged if implementation introduces it.

An optional AWS journal remains a separate **1,400 / 2,000 / 3,000** conditional
estimate. The published 0.3.0 donor has 1,755 AWS/auth/governance lines plus 1,721
incompatible old journal lines; the 145-line new protocol model is not a complete
AWS host. The newer upstream scope legitimately defers Apple/AWS certification,
so this backend is not silently added to the selected default or made an import
prerequisite. Future unbounded upstream-tree streaming is separately estimated
at 200 / 450 / 800; current bounded capability does not require it.

Tests and native oracles, fixtures/archives, build/research tooling, documentation,
generated declarations and delivery bundles are separate maintained lanes. The
retirement map removes the obsolete research framework as an active authority;
preserved independent experiments and archived inputs remain available. None of
those deletions are counted toward the product-source reduction.
