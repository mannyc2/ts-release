# Release templates

The [npm/GitHub application](npm-github/README.md) is the runnable 0.4.2 starter.
Its application JavaScript is generated from the repository's production
self-release source; CI installs the retained packages and exercises that code.

The other JSON configurations and workflow examples in this directory target the
retired configuration-driven interface. They are retained as design examples,
not executable starting points for 0.4. Use the current application contract in
`docs/preparation.md` and the Action example in the root README.
